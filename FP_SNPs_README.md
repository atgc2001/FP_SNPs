# Использование скрипта FP_SNPs
Скрипт запускается командой

    python -r [файл_с_референсным_геномом.fa] -i [файл_с_аллелями.tsv]
-o [выходной_файл] необязательный параметр

В качестве референсного генома использовался файл GRCh38.d1.vd1.fa, находящийся в архиве GRCh38.d1.vd1.fa.tar.gz (доступен по адресу https://gdc.cancer.gov/about-data/data-harmonization-and-generation/gdc-reference-files).
